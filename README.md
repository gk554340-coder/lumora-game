# LUMORA

LUMORA is an original endless puzzle adventure game designed as a scalable mobile gaming application.

## Core Vision

Play → Solve → Reward → Progress → Discover → Unlock → Repeat

## Core Principles

- Endless level progression
- Increasing difficulty
- Original puzzle mechanics
- Server-authoritative game economy
- Secure token and reward system
- Premium currency
- Daily rewards
- Missions and streaks
- Live events
- Leaderboards
- Collection and progression
- Rewarded advertising
- In-app purchases
- Smart notifications
- Strong anti-cheat architecture
- Scalable backend
- Production-grade security

## Project Status

Development has started.

## Important Rule

The client must never be trusted with authoritative game economy, purchases, rewards, or security decisions.

All sensitive operations will be validated by the backend.
